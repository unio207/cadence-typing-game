# cadence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `cadence`, an endless browser typing game in which the ink dries as you type, you must keep up with a demand that only ever rises, and rhythm — the evenness of your keystrokes — is the score multiplier.

**Architecture:** All game logic lives in small plain-JavaScript files under `src/`, loaded by `index.html` with classic `<script>` tags (not ES modules, which browsers block under `file://`). Each file exports through a dual footer so the same source runs in the browser *and* under `node --test`, which is what makes the pure logic — generator, metrics, survival model, run state machine — testable without a bundler, a package manager, or a browser automation harness. The DOM layer (renderer, rail, screens) is thin by design and verified in the browser against stated observations. A final task adds a ~40-line inliner producing a single distributable `cadence.html`.

**Tech Stack:** Vanilla JavaScript (ES2020), HTML, CSS custom properties, one `<canvas>`. `node --test` with `node:test` and `node:assert/strict` for tests (Node 26 confirmed present; no `npm install`, no dependencies, no `package.json` required). IBM Plex Mono from Google Fonts with a `ui-monospace` fallback.

**Spec:** `docs/superpowers/specs/2026-10-01-cadence-typing-game-design.md`

## Global Constraints

Copied verbatim from the spec. Every task's requirements implicitly include these.

- **One deliverable the player opens.** `index.html` must run by double-clicking it from the filesystem — no build step required to play, no server, no dependencies to install.
- **Deliberate deviation from spec §12, flagged:** the spec says "one `index.html`". This plan ships `index.html` plus `src/*.js` classic scripts during development, because a single file cannot be unit-tested without a build step, and Task 14 adds an optional inliner that produces a single-file `cadence.html` for sharing. Playing never requires the inliner.
- **No audio.** No sound of any kind.
- **Content is lowercase only** — no punctuation, no capitals, no digits. Shift and caps lock are never required.
- **Errors are let through.** No stop-on-error, no freeze, no backspace, no desync.
- **Nothing blinks, flashes, shakes or glows.** Two easing curves only: `cubic-bezier(.33,1,.68,1)` for UI and a critically-damped spring for caret and scroll.
- **Palette (CSS custom properties on `:root`):** `--paper #f7f4ec`, `--ink #17171a`, `--ink-done #c2bdb0`, `--mute #a3a098`, `--rule #e6e2d7`, `--red #b4412f`.
- **Red appears only** for error characters, strikes, the demand notch, and a new record.
- **Type is IBM Plex Mono at weights 400 and 500 only.** 450 is not a real weight and must not be used.
- **All numerals use `font-variant-numeric: tabular-nums`.**
- **Survival constants:** `W = 40`; `base = clamp((ratio - 0.85)/0.50, 0, 1)`; `f = 0.85*W*clamp((0.94 - ratio)/0.40, 0, 1)`; `opacity(d) = base + (1-base)*clamp((d-f)/(W-f),0,1)^0.8`; `blind = opacity(0) < 0.18`.
- **Demand:** starts at 40, is a state variable, and rises every frame by `max(0.5, (0.85*sustained - demand) * 0.07) * dt`. It must never decrease and must never plateau.
- **Scoring:** `10 * clamp(v/60,0.5,3) * (0.6 + 0.9*rhythm/100) * (1 + min(combo,300)/300)` per correct character.
- **Rhythm:** median absolute deviation over the last 16 intervals, each clamped to 600ms; `rhythm = round(100*(1 - clamp(cv/0.5,0,1)))`; fewer than 8 intervals yields 50.
- **Keystrokes are timestamped in the `keydown` handler before any rendering work.**
- **Desktop only.** Keyboard required.
- **Every `src/*.js` file ends with this exact dual-export footer**, with its own API object:

```js
  const api = { /* names */ };
  if (typeof module !== 'undefined' && module.exports) module.exports = api;
  else root.cadence = Object.assign(root.cadence || {}, api);
})(typeof globalThis !== 'undefined' ? globalThis : this);
```

Create `src/keymap.js`:

```js
(function (root) {
  'use strict';

  const ROWS = {
    top: 'qwertyuiop',
    home: 'asdfghjkl',
    bottom: 'zxcvbnm'
  };

  // 0-3 left pinky..index, 5 thumb, 6-9 right index..pinky
  const FINGERS = {
    q: 0, a: 0, z: 0,
    w: 1, s: 1, x: 1,
    e: 2, d: 2, c: 2,
    r: 3, f: 3, v: 3, t: 3, g: 3, b: 3,
    y: 6, h: 6, n: 6, u: 6, j: 6, m: 6,
    i: 7, k: 7,
    o: 8, l: 8,
    p: 9
  };

  function keyInfo(ch) {
    if (ch === ' ') return { hand: 'T', row: 'space', finger: 5 };
    const finger = FINGERS[ch];
    if (finger === undefined) return null;
    let row = null;
    for (const name of Object.keys(ROWS)) {
      if (ROWS[name].indexOf(ch) !== -1) { row = name; break; }
    }
    return { hand: finger <= 3 ? 'L' : 'R', row: row, finger: finger };
  }

  function tagWord(word) {
    const infos = [];
    for (const ch of word) {
      const info = keyInfo(ch);
      if (!info) throw new Error('word "' + word + '" contains unmappable "' + ch + '"');
      infos.push(info);
    }

    const hands = infos.map(i => i.hand).join('');
    const rows = infos.map(i => i.row[0]).join('');   // t | h | b
    const fingers = infos.map(i => i.finger);

    let home = 0, top = 0, alt = 0, run = 1, maxRun = 1, sameFinger = 0;
    for (let i = 0; i < infos.length; i++) {
      if (infos[i].row === 'home') home++;
      if (infos[i].row === 'top') top++;
      if (i > 0) {
        if (infos[i].hand !== infos[i - 1].hand) { alt++; run = 1; }
        else { run++; if (run > maxRun) maxRun = run; }
        if (infos[i].finger === infos[i - 1].finger && word[i] !== word[i - 1]) sameFinger++;
      }
    }

    const transitions = Math.max(1, infos.length - 1);
    const left = hands.split('').filter(h => h === 'L').length;
    const right = hands.length - left;

    return {
      word: word,
      len: word.length,
      hands: hands,
      rows: rows,
      fingers: fingers,
      homeFrac: home / word.length,
      topFrac: top / word.length,
      altFrac: infos.length > 1 ? alt / transitions : 0,
      maxSameHandRun: maxRun,
      sameFingerPairs: sameFinger,
      hand: right > left ? 'R' : 'L'
    };
  }

  const api = { keyInfo, tagWord, ROWS, FINGERS };
  if (typeof module !== 'undefined' && module.exports) module.exports = api;
  else root.cadence = Object.assign(root.cadence || {}, api);
})(typeof globalThis !== 'undefined' ? globalThis : this);
```

### Task 3: Text generator

**Files:**
- Create: `src/generator.js`
- Create: `test/generator.test.js`

**Interfaces:**
- Consumes: `tagWord` from `src/keymap.js`; `WORDS`, `TOP200` from `src/words.js`.
- Produces:
  - `CHAPTERS` — array of 8 `{key, name, from, filter}` ordered by ascending `from` (the demand at which the chapter begins): 40 `open field`, 60 `home ground`, 80 `common tongue`, 100 `short work`, 120 `inward roll`, 140 `long form`, 160 `one hand`, 180 `thin air`.
  - `makeRng(seed) -> () => number` — mulberry32, returns floats in `[0,1)`.
  - `chapterAt(demand) -> index` — the highest chapter whose `from <= demand`, minimum 0.
  - `createGenerator(seed) -> gen` with `gen.words(chapterIndex, n) -> string[]` and `gen.recent` (the trailing window used for rejection).
  - `rejects(candidateTag, recentTags, chapterIndex) -> string | null` — the name of the rule that rejected the candidate, or `null` if accepted.

```js
(function (root) {
  'use strict';

  const km = (typeof require !== 'undefined') ? require('./keymap.js') : root.cadence;
  const wd = (typeof require !== 'undefined') ? require('./words.js') : root.cadence;
  const tagWord = km.tagWord;
  const WORDS = wd.WORDS;
  const TOP200 = wd.TOP200;

  const ROLL_BIGRAMS = [
    'oi','io','er','re','we','ew','po','op','lk','kl','ui','iu',
    'ol','lo','ki','ik','sd','ds','df','fd','as','sa','ty','rt'
  ];

  function hasRoll(word) {
    for (let i = 0; i < word.length - 1; i++) {
      if (ROLL_BIGRAMS.indexOf(word.slice(i, i + 2)) !== -1) return true;
    }
    return false;
  }

  const CHAPTERS = [
    { key: 'open-field',    name: 'open field',    from: 40,  filter: t => t.altFrac >= 0.6 },
    { key: 'home-ground',   name: 'home ground',   from: 60,  filter: t => t.homeFrac >= 0.7 },
    { key: 'common-tongue', name: 'common tongue', from: 80,  filter: t => TOP200.has(t.word) },
    { key: 'short-work',    name: 'short work',    from: 100, filter: t => t.len <= 4 },
    { key: 'inward-roll',   name: 'inward roll',   from: 120, filter: t => hasRoll(t.word) },
    { key: 'long-form',     name: 'long form',     from: 140, filter: t => t.len >= 6 },
    { key: 'one-hand',      name: 'one hand',      from: 160, filter: t => t.maxSameHandRun >= 3 },
    { key: 'thin-air',      name: 'thin air',      from: 180, filter: t => t.topFrac >= 0.7 }
  ];

  function chapterAt(demand) {
    let idx = 0;
    for (let i = 0; i < CHAPTERS.length; i++) {
      if (demand >= CHAPTERS[i].from) idx = i;
    }
    return idx;
  }

  function makeRng(seed) {
    let a = seed >>> 0;
    return function () {
      a = (a + 0x6D2B79F5) >>> 0;
      let t = Math.imul(a ^ (a >>> 15), 1 | a);
      t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
      return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
    };
  }

  function rejects(cand, recentTags, chapterIndex) {
    const recent = recentTags.slice(-12);
    for (const r of recent) {
      if (r.word === cand.word) return 'repeat';
    }

    const prev = recent[recent.length - 1];
    const prev2 = recent[recent.length - 2];

    if (prev && prev2 &&
        prev.word[0] === cand.word[0] && prev2.word[0] === cand.word[0]) {
      return 'same-start';
    }

    if (prev) {
      const last = prev.word[prev.word.length - 1];
      const first = cand.word[0];
      const a = km.keyInfo(last), b = km.keyInfo(first);
      if (a && b && a.finger === b.finger && last !== first) return 'same-finger-boundary';
    }

    const isOneHand = CHAPTERS[chapterIndex].key === 'one-hand';
    if (!isOneHand && prev && prev2 &&
        prev.hand === cand.hand && prev2.hand === cand.hand) {
      return 'same-hand-run';
    }

    return null;
  }

  function scoreCandidate(cand, prev, chapterIndex) {
    let s = 0;
    if (prev) {
      const last = km.keyInfo(prev.word[prev.word.length - 1]);
      const first = km.keyInfo(cand.word[0]);
      if (last && first && last.hand !== first.hand) s += 2;   // prefer alternating hand-off
    }
    if (CHAPTERS[chapterIndex].key === 'inward-roll' && hasRoll(cand.word)) s += 2;
    s -= cand.sameFingerPairs;
    return s;
  }

  const POOL_CACHE = {};

  function poolFor(chapterIndex) {
    if (!POOL_CACHE[chapterIndex]) {
      const filter = CHAPTERS[chapterIndex].filter;
      POOL_CACHE[chapterIndex] = WORDS.map(tagWord).filter(filter);
    }
    return POOL_CACHE[chapterIndex];
  }

  function createGenerator(seed) {
    const rng = makeRng(seed);
    const recent = [];

    function nextWord(chapterIndex) {
      const pool = poolFor(chapterIndex);
      let best = null, bestScore = -Infinity;
      // sample up to 8 legal candidates and keep the best scoring one
      for (let attempt = 0; attempt < 64 && (best === null || attempt < 8); attempt++) {
        const cand = pool[Math.floor(rng() * pool.length)];
        if (rejects(cand, recent, chapterIndex) !== null) continue;
        const s = scoreCandidate(cand, recent[recent.length - 1], chapterIndex);
        if (s > bestScore) { bestScore = s; best = cand; }
      }
      if (best === null) {
        // exhaustive fallback: the pool is small enough that this is cheap and
        // guarantees we never stall mid-run
        for (const cand of pool) {
          if (rejects(cand, recent, chapterIndex) === null) { best = cand; break; }
        }
      }
      if (best === null) throw new Error('no legal word for chapter ' + chapterIndex);
      recent.push(best);
      if (recent.length > 12) recent.shift();
      return best.word;
    }

    return {
      recent: recent,
      words: function (chapterIndex, n) {
        const out = [];
        for (let i = 0; i < n; i++) out.push(nextWord(chapterIndex));
        return out;
      }
    };
  }

  const api = { CHAPTERS, chapterAt, makeRng, createGenerator, rejects, hasRoll };
  if (typeof module !== 'undefined' && module.exports) module.exports = api;
  else root.cadence = Object.assign(root.cadence || {}, api);
})(typeof globalThis !== 'undefined' ? globalThis : this);
```

```js
(function (root) {
  'use strict';

  const RHYTHM_WINDOW = 16;
  const RHYTHM_MIN_SAMPLES = 8;
  const INTERVAL_CLAMP_MS = 600;
  const CV_AT_ZERO = 0.5;

  function clamp(x, lo, hi) { return x < lo ? lo : (x > hi ? hi : x); }

  function median(nums) {
    const xs = nums.slice().sort((a, b) => a - b);
    if (xs.length === 0) return 0;
    const mid = xs.length >> 1;
    return xs.length % 2 ? xs[mid] : (xs[mid - 1] + xs[mid]) / 2;
  }

  function rhythmOf(intervals) {
    const xs = intervals
      .slice(-RHYTHM_WINDOW)
      .map(d => Math.min(d, INTERVAL_CLAMP_MS));
    if (xs.length < RHYTHM_MIN_SAMPLES) return 50;

    const m = median(xs);
    if (m === 0) return 0;
    const mad = median(xs.map(d => Math.abs(d - m)));
    const cv = clamp(mad / m, 0, 1);
    return Math.round(100 * (1 - clamp(cv / CV_AT_ZERO, 0, 1)));
  }

  const api = { clamp, median, rhythmOf, RHYTHM_WINDOW, INTERVAL_CLAMP_MS };
  if (typeof module !== 'undefined' && module.exports) module.exports = api;
  else root.cadence = Object.assign(root.cadence || {}, api);
})(typeof globalThis !== 'undefined' ? globalThis : this);
```

```js
  const SPEED_WINDOW_MS = 3000;

  function createSpeed() { return { times: [] }; }

  function pushKey(speed, nowMs) {
    speed.times.push(nowMs);
    if (speed.times.length > 512) speed.times.splice(0, speed.times.length - 512);
  }

  function wpmAt(speed, nowMs) {
    const cutoff = nowMs - SPEED_WINDOW_MS;
    let n = 0;
    for (let i = speed.times.length - 1; i >= 0; i--) {
      if (speed.times[i] < cutoff) break;
      n++;
    }
    if (n === 0) return 0;
    // characters -> words (/5) -> per minute (window is 3s = 1/20 min)
    return (n / 5) * (60000 / SPEED_WINDOW_MS);
  }

  function pointsFor(v, rhythm, combo) {
    const speedMult = clamp(v / 60, 0.5, 3.0);
    const rhythmMult = 0.6 + 0.9 * (rhythm / 100);
    const comboMult = 1 + Math.min(combo, 300) / 300;
    return 10 * speedMult * rhythmMult * comboMult;
  }
```

```js
(function (root) {
  'use strict';

  const m = (typeof require !== 'undefined') ? require('./metrics.js') : root.cadence;
  const clamp = m.clamp;
  const median = m.median;

  const W = 40;                  // read-ahead window, characters
  const LEGIBLE = 0.18;          // opacity below which a character is unreadable
  const SAMPLE_EVERY_MS = 250;
  const SAMPLE_WINDOW = 80;      // 80 * 250ms = 20s
  const TARGET_FRACTION = 0.85;
  const EASE_PER_SECOND = 0.07;  // ~15s time constant
  const MIN_RISE_PER_SECOND = 0.5;

  function createDemand() {
    return { value: 40, samples: [], lastSampleAt: -Infinity };
  }

  function sampleSpeed(demand, v, nowMs) {
    if (nowMs - demand.lastSampleAt < SAMPLE_EVERY_MS) return;
    demand.lastSampleAt = nowMs;
    demand.samples.push(v);
    if (demand.samples.length > SAMPLE_WINDOW) demand.samples.shift();
  }

  function sustainedOf(demand) {
    if (demand.samples.length < 4) return 40;
    return median(demand.samples);
  }

  function stepDemand(demand, dtSeconds) {
    const target = TARGET_FRACTION * sustainedOf(demand);
    const eased = (target - demand.value) * EASE_PER_SECOND;
    demand.value += Math.max(MIN_RISE_PER_SECOND, eased) * dtSeconds;
    return demand.value;
  }

  function baseInk(ratio) {
    return clamp((ratio - 0.85) / 0.50, 0, 1);
  }

  function frontWidth(ratio) {
    return 0.85 * W * clamp((0.94 - ratio) / 0.40, 0, 1);
  }

  function opacityAt(d, ratio) {
    const base = baseInk(ratio);
    const f = frontWidth(ratio);
    const t = clamp((d - f) / (W - f), 0, 1);
    return base + (1 - base) * Math.pow(t, 0.8);
  }

  function isBlind(ratio) {
    return opacityAt(0, ratio) < LEGIBLE;
  }

  function unreadableWidth(ratio) {
    if (!isBlind(ratio)) return 0;
    const base = baseInk(ratio);
    const f = frontWidth(ratio);
    // solve base + (1-base) * t^0.8 = LEGIBLE  for d
    const t = Math.pow((LEGIBLE - base) / (1 - base), 1 / 0.8);
    return f + t * (W - f);
  }

  const api = {
    W, LEGIBLE, createDemand, sampleSpeed, sustainedOf, stepDemand,
    baseInk, frontWidth, opacityAt, isBlind, unreadableWidth
  };
  if (typeof module !== 'undefined' && module.exports) module.exports = api;
  else root.cadence = Object.assign(root.cadence || {}, api);
})(typeof globalThis !== 'undefined' ? globalThis : this);
```

```js
(function (root) {
  'use strict';

  const req = (typeof require !== 'undefined');
  const m = req ? require('./metrics.js') : root.cadence;
  const s = req ? require('./survival.js') : root.cadence;
  const g = req ? require('./generator.js') : root.cadence;

  const MAX_STRIKES = 3;
  const STALL_MS = 2000;
  const LOOKAHEAD = 200;     // keep at least this many characters past the cursor
  const CHUNK_WORDS = 40;

  function topUp(run) {
    while (run.text.length < run.cursor + LOOKAHEAD) {
      const words = run.gen.words(run.chapterIndex, CHUNK_WORDS);
      run.text += (run.text.length ? ' ' : '') + words.join(' ');
    }
  }

  function createRun(seed) {
    const run = {
      seed: seed,
      gen: g.createGenerator(seed),
      text: '',
      cursor: 0,
      marks: [],
      combo: 0,
      maxCombo: 0,
      score: 0,
      strikes: 0,
      correct: 0,
      total: 0,
      v: 0,
      peakV: 0,
      ratio: 1,
      rhythm: 50,
      chapterIndex: 0,
      startedAt: null,
      lastKeyAt: null,
      intervals: [],
      blindSince: null,
      ended: false,
      endReason: null,
      demand: s.createDemand(),
      speed: m.createSpeed(),
      wpmTrace: []
    };
    topUp(run);
    return run;
  }

  function endRun(run, reason) {
    run.ended = true;
    run.endReason = reason;
  }

  function onKey(run, key, nowMs) {
    if (run.ended) return { correct: false, wasBlind: false, strike: false, ended: true };
    if (run.startedAt === null) run.startedAt = nowMs;

    const wasBlind = s.isBlind(run.ratio);
    const expected = run.text[run.cursor];
    const correct = key === expected;

    if (run.lastKeyAt !== null) {
      run.intervals.push(nowMs - run.lastKeyAt);
      if (run.intervals.length > 64) run.intervals.shift();
    }
    run.lastKeyAt = nowMs;

    m.pushKey(run.speed, nowMs);
    run.v = m.wpmAt(run.speed, nowMs);
    if (run.v > run.peakV) run.peakV = run.v;
    run.rhythm = m.rhythmOf(run.intervals);

    run.total++;
    run.marks[run.cursor] = correct ? 'ok' : 'err';
    run.cursor++;

    let strike = false;
    if (correct) {
      run.correct++;
      run.combo++;
      if (run.combo > run.maxCombo) run.maxCombo = run.combo;
      run.score += m.pointsFor(run.v, run.rhythm, run.combo);
      run.blindSince = wasBlind ? nowMs : null;   // a correct key buys you time
    } else {
      run.combo = 0;
      if (wasBlind) {
        strike = true;
        run.strikes++;
        if (run.strikes >= MAX_STRIKES) endRun(run, 'strikes');
      }
    }

    topUp(run);
    return { correct: correct, wasBlind: wasBlind, strike: strike, ended: run.ended };
  }

  function tick(run, nowMs, dtSeconds) {
    if (run.ended || run.startedAt === null) return;

    run.v = m.wpmAt(run.speed, nowMs);
    s.sampleSpeed(run.demand, run.v, nowMs);
    s.stepDemand(run.demand, dtSeconds);
    run.ratio = run.demand.value > 0 ? run.v / run.demand.value : 0;

    const next = g.chapterAt(run.demand.value);
    if (next > run.chapterIndex) run.chapterIndex = next;

    if (s.isBlind(run.ratio)) {
      if (run.blindSince === null) run.blindSince = nowMs;
      else if (nowMs - run.blindSince >= STALL_MS) endRun(run, 'dried');
    } else {
      run.blindSince = null;
    }

    run.wpmTrace.push({ t: nowMs - run.startedAt, v: run.v, demand: run.demand.value });
    if (run.wpmTrace.length > 4000) run.wpmTrace.shift();
  }

  const api = { createRun, onKey, tick, MAX_STRIKES, STALL_MS, LOOKAHEAD };
  if (typeof module !== 'undefined' && module.exports) module.exports = api;
  else root.cadence = Object.assign(root.cadence || {}, api);
})(typeof globalThis !== 'undefined' ? globalThis : this);
```

### Task 9: Renderer and the inverting block caret

**Files:**
- Modify: `src/render.js` (replace the placeholder entirely)

**Interfaces:**
- Consumes: `opacityAt`, `W` from `src/survival.js`.
- Produces:
  - `createRenderer(els) -> renderer`, where `els` is `{line, caret, caretLine, track}`.
  - `renderer.measure()` — measures and caches `charWidth` from a hidden sample; call after `document.fonts.ready` and on `resize`.
  - `renderer.draw(run, dtSeconds)` — reconciles spans, writes per-character opacity for the 40 characters ahead of the cursor, and advances the spring-eased scroll and caret.
  - `renderer.charWidth` — the measured advance width in px.

Two rules this task exists to honour: spans are **reused**, never recreated per keystroke, and the scroll position is a **continuous float**, never a character index.

- [ ] **Step 1: Write the implementation**

Replace `src/render.js` with:

```js
(function (root) {
  'use strict';

  const req = (typeof require !== 'undefined');
  const s = req ? require('./survival.js') : root.cadence;

  const WINDOW_BEHIND = 60;
  const WINDOW_AHEAD = 90;
  const SCROLL_K = 14;
  const CARET_K = 9;

  function createRenderer(els) {
    const state = {
      charWidth: 0,
      x: 0,            // continuous scroll position, px
      caretX: 0,       // continuous caret position, px
      first: -1,       // index of the first rendered character
      spans: [],
      caretSpans: []
    };

    function measure() {
      const probe = document.createElement('span');
      probe.textContent = 'mmmmmmmmmm';
      probe.style.cssText =
        'position:absolute;visibility:hidden;white-space:pre;font-size:30px;letter-spacing:-.01em';
      probe.style.fontFamily = getComputedStyle(els.line).fontFamily;
      document.body.appendChild(probe);
      state.charWidth = probe.getBoundingClientRect().width / 10;
      probe.remove();
    }

    function ensureSpans(host, bank, count) {
      while (bank.length < count) {
        const sp = document.createElement('span');
        host.appendChild(sp);
        bank.push(sp);
      }
      for (let i = count; i < bank.length; i++) bank[i].textContent = '';
    }

    function draw(run, dt) {
      if (!state.charWidth) measure();

      const first = Math.max(0, run.cursor - WINDOW_BEHIND);
      const last = Math.min(run.text.length, run.cursor + WINDOW_AHEAD);
      const count = last - first;

      ensureSpans(els.line, state.spans, count);
      ensureSpans(els.caretLine, state.caretSpans, count);

      for (let i = 0; i < count; i++) {
        const idx = first + i;
        const ch = run.text[idx];
        const span = state.spans[i];
        const twin = state.caretSpans[i];

        if (span.textContent !== ch) { span.textContent = ch; twin.textContent = ch; }

        if (idx < run.cursor) {
          const cls = run.marks[idx] === 'err' ? 'err' : 'done';
          if (span.className !== cls) span.className = cls;
          if (span.style.opacity !== '') span.style.opacity = '';
        } else {
          if (span.className !== '') span.className = '';
          const d = idx - run.cursor;
          const o = d >= s.W ? 1 : s.opacityAt(d, run.ratio);
          const rounded = o.toFixed(3);
          if (span.style.opacity !== rounded) span.style.opacity = rounded;
        }
      }

      // continuous float scroll, spring eased - never a character index
      const targetX = -(run.cursor - first) * state.charWidth;
      const kScroll = 1 - Math.exp(-SCROLL_K * dt);
      const kCaret = 1 - Math.exp(-CARET_K * dt);
      state.x += (targetX - state.x) * kScroll;
      state.caretX += (targetX - state.caretX) * kCaret;

      els.line.style.transform = 'translate(' + state.x.toFixed(2) + 'px, -50%)';
      els.caretLine.style.transform =
        'translate(' + (state.caretX + (first - first) * state.charWidth).toFixed(2) + 'px, -50%)';
      els.caret.style.transform =
        'translate(' + (state.caretX - targetX).toFixed(2) + 'px, -50%)';

      state.first = first;
    }

    function reset() {
      state.x = 0; state.caretX = 0; state.first = -1;
      for (const sp of state.spans) { sp.textContent = ''; sp.className = ''; sp.style.opacity = ''; }
      for (const sp of state.caretSpans) sp.textContent = '';
    }

    return {
      measure: measure,
      draw: draw,
      reset: reset,
      get charWidth() { return state.charWidth; }
    };
  }

  const api = { createRenderer };
  if (typeof module !== 'undefined' && module.exports) module.exports = api;
  else root.cadence = Object.assign(root.cadence || {}, api);
})(typeof globalThis !== 'undefined' ? globalThis : this);
```

### Task 10: The rhythm rail

**Files:**
- Modify: `src/rail.js` (replace the placeholder entirely)

**Interfaces:**
- Consumes: nothing.
- Produces: `createRail(canvas) -> rail` with `rail.resize()`, `rail.mark(nowMs)` (record one keystroke), `rail.draw(nowMs, rhythm)`, and `rail.reset()`. Holds a 400-entry ring buffer of timestamps and scrolls at a fixed 90 px/s.

- [ ] **Step 1: Write the implementation**

Replace `src/rail.js` with:

```js
(function (root) {
  'use strict';

  const PX_PER_MS = 0.09;     // 90 px/s
  const CAPACITY = 400;
  const TICK_H = 13;

  function createRail(canvas) {
    const ctx = canvas.getContext('2d');
    const times = [];
    let dpr = 1, w = 0, h = 0;

    function resize() {
      dpr = window.devicePixelRatio || 1;
      const rect = canvas.getBoundingClientRect();
      w = rect.width; h = rect.height;
      canvas.width = Math.round(w * dpr);
      canvas.height = Math.round(h * dpr);
      ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    }

    function mark(nowMs) {
      times.push(nowMs);
      if (times.length > CAPACITY) times.shift();
    }

    function draw(nowMs, rhythm) {
      if (!w) resize();
      const styles = getComputedStyle(document.documentElement);
      const ink = styles.getPropertyValue('--ink').trim() || '#17171a';
      const rule = styles.getPropertyValue('--rule').trim() || '#e6e2d7';

      ctx.clearRect(0, 0, w, h);

      // the baseline
      ctx.fillStyle = rule;
      ctx.fillRect(0, Math.round(h / 2), w, 1);

      // ticks, newest at the right edge, scrolling left with time
      ctx.fillStyle = ink;
      ctx.globalAlpha = 0.3 + 0.55 * (rhythm / 100);
      const top = Math.round((h - TICK_H) / 2);
      for (let i = times.length - 1; i >= 0; i--) {
        const x = w - (nowMs - times[i]) * PX_PER_MS;
        if (x < -2) break;
        if (x > w) continue;
        ctx.fillRect(Math.round(x), top, 1, TICK_H);
      }
      ctx.globalAlpha = 1;
    }

    function reset() { times.length = 0; }

    resize();
    return { resize, mark, draw, reset };
  }

  const api = { createRail };
  if (typeof module !== 'undefined' && module.exports) module.exports = api;
  else root.cadence = Object.assign(root.cadence || {}, api);
})(typeof globalThis !== 'undefined' ? globalThis : this);
```

```js
    // the bar: your wpm as the fill, the demand as a notch, both on a 0-220 scale

    els['bar-fill'].style.width = Math.min(100, (run.v / scale) * 100) + '%';
    els['bar-notch'].style.left = Math.min(100, (run.demand.value / scale) * 100) + '%';
  }

    requestAnimationFrame(frame);
    const dt = Math.min(0.05, (now - app.lastFrame) / 1000);

    if (app.screen !== 'run' || !app.run) return;

    c.tick(app.run, now, dt);

    app.rail.draw(now, app.run.rhythm);

    window.addEventListener('keydown', onKeyDown);

    requestAnimationFrame(frame);
  }

  root.cadenceApp = { startRun, finishRun, state: app, els: els, boot: boot };

  if (document.readyState === 'loading') {
    document.addEventListener('DOMContentLoaded', boot);
  } else {
    boot();
  }
})(typeof globalThis !== 'undefined' ? globalThis : this);
```

```js
  const DEFAULTS = { v: 1, longest: null, highest: null };

    return r && typeof r === 'object' &&
      typeof r.ms === 'number' && typeof r.score === 'number';
  }

  function loadRecords() {
    let raw = null;
    try { raw = localStorage.getItem(KEY); } catch (e) { return Object.assign({}, DEFAULTS); }
    if (!raw) return Object.assign({}, DEFAULTS);
    let parsed;
    try { parsed = JSON.parse(raw); } catch (e) { return Object.assign({}, DEFAULTS); }
    return {
      v: 1,
      longest: validRecord(parsed && parsed.longest) ? parsed.longest : null,
      highest: validRecord(parsed && parsed.highest) ? parsed.highest : null
    };
  }

  function saveRecords(records) {
    try { localStorage.setItem(KEY, JSON.stringify(records)); } catch (e) { /* ignore */ }
  }

    return {
      ms: run.ms !== undefined ? run.ms : 0,
      score: Math.round(run.score || 0),
      wpm: Math.round(run.wpm || 0),
      rhythm: Math.round(run.rhythm || 0),
      chapterIndex: run.chapterIndex || 0

    const recs = loadRecords();

      longest: !recs.longest || s.ms > recs.longest.ms,
      highest: !recs.highest || s.score > recs.highest.score
    };
    if (fell.longest) recs.longest = s;
    if (fell.highest) recs.highest = s;
    if (fell.longest || fell.highest) saveRecords(recs);
    return fell;
  }

    const total = Math.max(0, Math.floor(ms / 1000));
    const mins = Math.floor(total / 60);
    const secs = total % 60;
    return mins + ':' + String(secs).padStart(2, '0');
  }

    const s = summarise(run);
    return 'cadence · ' + formatDuration(s.ms) +
      ' · ' + s.score.toLocaleString('en-US') +
      ' · ' + s.wpm + 'wpm' +
      ' · r' + s.rhythm +
      ' · chapter ' + (s.chapterIndex + 1);
```

- [ ] **Step 1: Add the performance harness**

In `src/main.js`, immediately before `root.cadenceApp = ...`, add:

```js
  // ?perf=1 replays synthetic keystrokes at 160 wpm and reports frame cost.
  // input latency is the one thing that must not regress.
  function perfRun(seconds) {
    const frames = [];
    const msPerChar = 60000 / (160 * 5);
    let nextKeyAt = performance.now();
    const stop = performance.now() + seconds * 1000;
    let last = performance.now();

    startRun();

    function step(now) {
      const t0 = performance.now();
      while (nextKeyAt <= now && app.run && !app.run.ended) {
        c.onKey(app.run, app.run.text[app.run.cursor], nextKeyAt);
        app.rail.mark(nextKeyAt);
        nextKeyAt += msPerChar;
      }
      const dt = Math.min(0.05, (now - last) / 1000);
      last = now;
      if (app.run && !app.run.ended) {
        c.tick(app.run, now, dt);
        app.renderer.draw(app.run, dt);
        app.rail.draw(now, app.run.rhythm);
        updateHud(app.run);
      }
      frames.push(performance.now() - t0);

      if (now < stop) requestAnimationFrame(step);
      else {
        const sorted = frames.slice().sort((a, b) => a - b);
        const p = q => sorted[Math.floor(q * (sorted.length - 1))].toFixed(2);
        console.log('[perf] frames=' + frames.length +
          ' median=' + p(0.5) + 'ms p95=' + p(0.95) + 'ms max=' + p(1) + 'ms');
      }
    }
    requestAnimationFrame(step);
  }
```

```js
#!/usr/bin/env node
'use strict';

// Inlines every <script src="src/*.js"> into a single distributable file.
// Playing never requires this - index.html runs directly from the filesystem.
// This exists so the game can be sent to someone as one file.

const fs = require('node:fs');
const path = require('node:path');

const rootDir = path.join(__dirname, '..');
const html = fs.readFileSync(path.join(rootDir, 'index.html'), 'utf8');

const SCRIPT = /[ \t]*<script src="(src\/[^"]+)"><\/script>\n?/g;
let inlined = 0;

const out = html.replace(SCRIPT, (_match, src) => {
  const code = fs.readFileSync(path.join(rootDir, src), 'utf8');
  inlined++;
  return '<script>\n/* ' + src + ' */\n' + code + '</script>\n';
});

if (inlined === 0) {
  console.error('bundle: no <script src="src/..."> tags found in index.html');
  process.exit(1);
}
if (/<script src="src\//.test(out)) {
  console.error('bundle: some script tags were not inlined');
  process.exit(1);
}

const dest = path.join(rootDir, 'cadence.html');
fs.writeFileSync(dest, out);
console.log('bundle: inlined ' + inlined + ' files -> ' + path.relative(rootDir, dest) +
  ' (' + (out.length / 1024).toFixed(1) + ' kB)');
```
